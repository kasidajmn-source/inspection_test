# Construction Checklist — เว็บแบบฟอร์มตรวจสอบงานก่อสร้าง

เว็บไซต์ไฟล์เดียว (`index.html`) ไม่ต้อง build ไม่ต้องลง dependency ใดๆ เปิดใช้ได้ทั้งบนเครื่องและบน GitHub Pages

## ฟีเจอร์

- ข้อมูลโครงการ: ชื่อโครงการ / เลขที่สัญญา / วันที่ตรวจสอบ / ผู้รับจ้าง / ผู้ว่าจ้าง / สถานที่ / งวดงาน / ผู้ตรวจสอบ / สภาพอากาศ / ช่วงเวลา
- เลขที่เอกสาร + แก้ไขครั้งที่ + ใส่โลโก้หน่วยงานได้ (คลิกที่กล่องสีเหลืองมุมบนซ้าย)
- รายการตรวจสอบแบ่งเป็นหมวด แต่ละรายการมี **ผ่าน / ไม่ผ่าน / N.A. + หมายเหตุ + ช่องเกณฑ์อ้างอิง**
- เทมเพลตสำเร็จรูป: งานโยธา/ก่อสร้างอาคาร (7 หมวด 40 รายการ) และ งานถนน/ระบบระบายน้ำ (7 หมวด 35 รายการ) หรือเริ่มจากฟอร์มเปล่า
- แก้ไขข้อความทุกช่องได้โดยตรง เพิ่ม/ลบ/ทำสำเนาหมวด เลื่อนลำดับหมวด
- สรุปผลอัตโนมัติ: จำนวนรายการทั้งหมด / ผ่าน / ไม่ผ่าน / N.A. / ยังไม่ตรวจ
- ออกเป็น PDF: กดปุ่ม "บันทึกเป็น PDF" → เลือกปลายทางเป็น Save as PDF (จัดหน้า A4 แนวตั้งพร้อมช่องลงนาม 3 ฝ่าย)
- บันทึกอัตโนมัติลงเครื่อง (localStorage) + ส่งออก/นำเข้าไฟล์ JSON เพื่อเก็บงานหรือส่งต่อ

## วิธีขึ้น GitHub Pages

วิธีที่ 1 — เว็บเดี่ยวที่ `https://<username>.github.io`

1. สร้าง repository ชื่อ `<username>.github.io` (ตั้งเป็น Public)
2. อัปโหลด `index.html` ไว้ที่ root ของ repo
3. รอ 1-2 นาที แล้วเปิด `https://<username>.github.io`

วิธีที่ 2 — เป็นโปรเจกต์ย่อยของ repo ที่มีอยู่

1. อัปโหลด `index.html` ขึ้น repo (branch `main`)
2. ไปที่ **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / โฟลเดอร์ `/ (root)` → Save
3. เปิด `https://<username>.github.io/<repo-name>/`

ผ่าน command line:

```bash
git init
git add index.html
git commit -m "add construction checklist"
git branch -M main
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

## ข้อควรรู้

- ข้อมูลที่กรอกถูกเก็บไว้ใน **เบราว์เซอร์ของเครื่องที่กรอกเท่านั้น** ไม่ได้ส่งขึ้นเซิร์ฟเวอร์ (เปิดคนละเครื่อง/คนละเบราว์เซอร์จะไม่เห็นข้อมูลกัน)
- เก็บได้ครั้งละ 1 ชุดในเครื่อง ถ้าจะตรวจหลายโครงการ ให้กด **↓ JSON** เก็บไฟล์ของโครงการเดิมไว้ก่อน แล้วค่อยเริ่มชุดใหม่ (กด **↑ นำเข้า** เพื่อเรียกกลับมาแก้ไข)
- ฟอนต์ใช้ Sarabun จาก Google Fonts ถ้าเปิดแบบออฟไลน์จะ fallback เป็นฟอนต์ระบบ แต่ใช้งานได้ปกติ
- แก้เทมเพลตรายการตรวจสอบได้ในไฟล์ `index.html` ที่ตัวแปร `TEMPLATES` (ในแท็ก `<script>`)
